How well can past repayment behaviour rank clients by next-month default risk, and how many observed defaults could an analyst find with a fixed review budget?

Repayment patterns and model evaluation

In the training set, the observed next-month default rate rose from 11.44% for clients with zero documented delay months to 69.86% for clients with six. MySQL reshaped the repayment history and generated client-level predictors for local analysis. An Excel PivotTable reproduced the training default rate of 22.12% from the SQL summary.

In Python, I fitted preprocessing and logistic regression on 18,000 training clients, used 6,000 validation clients to set a review cutoff, and evaluated the frozen model on 6,000 test clients. The report shows both ranking performance and how closely predicted probabilities matched observed default rates.

The fixed-capacity review queue measures how many observed defaults appeared among the highest-ranked clients. It does not estimate defaults prevented or financial savings.
