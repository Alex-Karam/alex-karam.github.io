Cookie Cats A/B Test

Did moving the first progression gate from level 30 to level 40 change how many players returned on day 7?

MySQL · Python / Jupyter · Power BI
View report PDF ↗ View SQL and notebook ↗

The public Cookie Cats dataset, shared by Mürşide Yarkın, contains 90,189 players. Retention uses all players assigned to each group as the denominator, including those who may never have reached the gate.

Keep the level-30 gate for now

The observed day-7 difference is about eight fewer returners per 1,000 assigned players at level 40. Before revisiting the rollout, verify the planned allocation and confirm that all players had complete day-7 follow-up.

Day-1 retention provides supporting context. It was 44.82% at level 30 and 44.23% at level 40.

Method and validation

Check assignments and outcomes

MySQL staging checks found 90,189 distinct player IDs and zero invalid IDs, assignment labels or retention flags.

Estimate the retention difference

Python reproduced the SQL counts and estimated a 95% confidence interval for the difference between two independent proportions.

The Power BI report calculates day-7 retention from the same two-row aggregate, dividing returners by assigned players for each group.

Allocation and follow-up checks

The observed split was 49.56% at level 30 and 50.44% at level 40. A Pearson chi-square check gave p = 0.0086 under a hypothetical independent 50:50 assignment. The planned ratio remains unverified.

Assignment logs and follow-up metadata were unavailable, so the cause of the split and completeness of day-7 coverage remain unknown. Gate exposure was also unavailable, so the estimate applies to assigned groups.
